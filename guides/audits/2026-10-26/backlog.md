## Priority and validation rules

Severity measures demonstrated impact/likelihood, not the amount of cleanup desired. Critical: immediate severe compromise/outage supported by evidence; High: material exploitable security/reliability exposure; Medium: bounded functional, privacy, delivery or maintainability defect; Low: conditional edge case, documentation gap or hardening. Confidence is evidentiary confidence, separate from severity. Optional style/architecture preferences are not defects.

All rows below are confirmed in source or safe local reproduction unless a narrower status is stated. The deployment collision itself remains unverified. No Critical finding was established. Functional duplicates retain the original IDs and are not counted again. Detailed locations, triggers, impact, evidence, fixes and effort are in the linked specialist reports.

## Testing follow-up

After fixing each reproduced defect, retain a targeted regression that fails on this snapshot and passes on the repair. The audit reproduction harness intentionally asserts today's broken behavior; it is evidence, not a passing product acceptance suite, and must not be added unchanged as a CI success gate.

The existing PR workflow runs encoding/lint/typecheck/build/manifest but omits form-origin, i18n, contact, customer-phone, newsletter, preference, token and product-image behavior scripts. Promote the isolated suites to PR checks with a Node runtime that supports their direct TypeScript imports, without adding live Redis/email/Shopify mutations. Test/runtime compatibility is a deliberate CI change; the current Node 22 application support declaration alone does not prove these scripts work on every Node 22 minor.

Add the missing regression checks in the same bounded repair batches, not a broad framework migration or coverage-percentage project. Keep authenticated OAuth/ownership/checkout and real provider checks as separately labeled integration gates with explicit test resources. See functional report for the distinction between absent coverage and observed failures.
